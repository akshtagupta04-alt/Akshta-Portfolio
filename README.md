# Akshta Gupta — Portfolio

Responsive, single-page portfolio website based on the supplied resume.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
Import this repository into Vercel. Select **Other** as the framework preset, leave the build command blank, and use `.` as the output directory. GitHub Pages can also serve the static files.

## Content
Includes profile, skills, five featured projects, education, certifications, GitHub, LinkedIn and email contact details.

## Project links
The resume supplied a GitHub profile but did not include individual repository URLs, so project links currently point to the GitHub profile. Replace them with direct repository URLs when confirmed.
