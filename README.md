## 💻 Run locally

No dependencies or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohitrath/Akshta-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Akshta-Portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code for local preview.

## ☁️ Deploy with Vercel

1. Sign in to [Vercel](https://vercel.com/).
2. Choose **Add New → Project**.
3. Import `Mohitrath/Akshta-Portfolio`.
4. Set the framework preset to **Other**.
5. Keep the root directory as `./`.
6. Leave the build command empty and deploy the static site.

Vercel can be connected to the GitHub repository to trigger a new deployment when changes are pushed.
